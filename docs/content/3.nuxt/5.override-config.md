For overriding config, there are two strategies. You can define your options in the Nuxt configuration file or you can pass them directly to the composable.

::tip 
A full list of options is available in the [api section](/api/options)
::

## Define options in Nuxt configuration

``` typescript [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ["@ambitiondev/nuxt-cookiebot"],
  cookiebot: {
    cookiebotId: 'COOKIEBOT_ID_HERE',
    autoConsentBanner: false,
    blockingMode: 'auto',
  },
});    
```

## Define options in the composable

``` vue [pages/index.vue]
<script setup lang="ts">
  const { consentBanner } = useCookiebot({
    autoConsentBanner: false,
    blockingMode: 'auto',
  });
</script>
```
