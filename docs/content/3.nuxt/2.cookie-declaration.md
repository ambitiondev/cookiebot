Once you have the app installed, the consent banner will be shown. If you're looking for a place to show your cookie policy, active cookies, and changes to consent, you can render the cookie declaration page in your Nuxt application.

::warning
The cookie declaration requires a DOM element to attach to, so it only works client side. The best way is to inject the script in an `onMounted` hook.
::

``` vue [pages/index.vue]
<script setup lang="ts">
  const cookieDeclarationRef = useTemplateRef('cookie-declaration');

  const { cookieDeclaration } = useCookiebot();

  onMounted(() => {
    cookieDeclaration(cookieDeclarationRef);
  });
</script>

<template>
	<div ref="cookie-declaration"></div>
</template>
```
