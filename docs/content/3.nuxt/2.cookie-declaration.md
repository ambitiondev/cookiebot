Once you have the app installed, the consent banner will be shown. If you're looking for a place to show your Cookie policy, active cookies and change of consent, you can render the Cookie declaration page in your Vue application.

``` vue [pages/index.vue]
<script setup lang="ts">
  const cookieDeclarationRef = useTemplateRef('cookie-declaration');

  const { cookieDeclaration } = useCookiebot();

  onMounted(() => {
    cookieDeclaration(cookieDeclarationRef);
  });
</script>

<template>
	<div ref="cookie-declaration"></div>
</template>
```
