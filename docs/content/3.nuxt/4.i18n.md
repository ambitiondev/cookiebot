## Inherit i18n language from Nuxt

Once you have the [@nuxtjs/i18n](https://i18n.nuxtjs.org/){target="_blank"} module set up in your Nuxt application, the application will automatically detect the current locale and pass it to the Cookiebot plugin. This allows you to use the app language to render the consent banner and cookie declaration.

## Override i18n language in Nuxt

If you want to override the locale with your own defined (stateful) locale, you can pass the `culture` property to the Cookiebot composable, like so:

::tip
Remember to set `autoConsentBanner` to `false` in your Nuxt configuration to prevent the app from automatically rendering the consent banner.
::

::note
The script required for the consent banner is loaded server side. The `culture` prop is therefore not reactive and will not update the banner if the locale changes after hydration.
::

::code-group
``` vue [pages/index.vue]
<script setup lang="ts">
  const computedLocale = computed(() => ...);

  const { consentBanner } = useCookiebot({
    culture: computedLocale.value,
  });

  consentBanner();
</script>

<template>
  <!-- Your template code here -->
</template>
```

``` typescript [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ["@ambitiondev/nuxt-cookiebot"],
  cookiebot: {
    autoConsentBanner: false,
    cookiebotId: 'COOKIEBOT_ID_HERE',
  },
});
```
::
