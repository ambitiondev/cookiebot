Once you have installed the plugin, you can modify your configuration to use `.env` or [Nuxt runtime variables](https://nuxt.com/docs/guide/going-further/runtime-config){target="blank"} for better management of your Cookiebot ID. This allows you to keep sensitive information out of your codebase and easily change configurations without modifying the source code, as well as configure different environments (development, staging, production) with ease.

## Using `.env` variables

::steps{level="3"}
### Create a `.env` file in the root of your Nuxt project
``` markdown [.env]
COOKIEBOT_ID=supersecret
```
### Include the environment variable in your Nuxt config
``` typescript [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ["@ambitiondev/nuxt-cookiebot"],
  cookiebot: {
    cookiebotId: import.meta.env.COOKIEBOT_ID,
  },
});
```
::

## Using Nuxt runtime config

::steps{level="3"}
### Define the runtime variable in your Nuxt config

::tip
Make sure to initialize your `cookiebotId` with an empty string for correct type generation.
:: 

``` typescript [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ["@ambitiondev/nuxt-cookiebot"],
  cookiebot: {
    useRuntimeConfig: true,
  },
  runtimeConfig: {
    public: {
      cookiebotId: '', // empty string for type generation
    },
  }
});
```

### Add the runtime variable in your `.env` file
``` markdown [.env]
NUXT_PUBLIC_COOKIEBOT_ID=supersecret
```
