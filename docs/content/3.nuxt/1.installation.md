::warning
The `cookieBotId` option has been renamed to `cookiebotId` as of version 4.0.0
::

::steps{level="3"}

### Install the package in your project
:::code-group

``` bash [npm]
npm install @ambitiondev/nuxt-cookiebot
```

```bash [pnpm]
pnpm add @ambitiondev/nuxt-cookiebot
```

```bash [yarn]
yarn add @ambitiondev/nuxt-cookiebot
```

```bun [bun]
bun add @ambitiondev/nuxt-cookiebot
```
:::

### Add the module in your Nuxt app

:::code-group
```typescript [module settings - nuxt.config.ts]
export default defineNuxtConfig({
  modules: ["@ambitiondev/nuxt-cookiebot"],
  cookiebot: {
    cookiebotId: 'COOKIEBOT_ID_HERE',
  },
});
```

```typescript [inline settings - nuxt.config.ts]
export default defineNuxtConfig({
  modules: [["@ambitiondev/nuxt-cookiebot", {
    cookiebotId: 'COOKIEBOT_ID_HERE',
  }]]
});
```
:::
