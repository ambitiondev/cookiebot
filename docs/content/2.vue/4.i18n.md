Once you have [vue-i18n](https://vue-i18n.intlify.dev/){target="_blank"} set up in your Vue application, you can easily integrate the Cookiebot plugin with i18n support. This allows you to manage translations for your Cookiebot consent banner and other related content.

To do so, you can add the `i18n.locale` property to your Cookiebot composable, like so:

``` vue [App.vue]
<script setup lang="ts">
  // Vendor
  import { useCookiebot } from '@ambitiondev/vue-cookiebot';
  import { onMounted, useTemplateRef } from 'vue';
  import { useI18n } from 'vue-i18n';

  // Refs
  const cookieDeclarationRef = useTemplateRef('cookie-declaration');

  // Composable
  const { locale } = useI18n();
  const { cookieDeclaration } = useCookiebot({
    culture: locale.value,
  });

  onMounted(() => {
    cookieDeclaration(cookieDeclarationRef);
  });
</script>

<template>
	<div ref="cookie-declaration"></div>
</template>
```
