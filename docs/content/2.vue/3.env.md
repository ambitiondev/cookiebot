Once you have installed the plugin, you can modify your configuration to use `.env` variables for better management of your Cookiebot ID. This allows you to keep sensitive information out of your codebase and easily change configurations without modifying the source code, as well as configure different environments (development, staging, production) with ease.

To use `.env` variables, follow these steps:

::steps{level="3"}

### Define the vite environment variable in your Typescript declaration file

``` ts [.env.d.ts]
/// <reference types="vite/client" />

interface ImportMetaEnv {
	readonly VITE_COOKIEBOT_ID: string;
}

interface ImportMeta {
	readonly env: ImportMetaEnv;
}
```

### Add the environment variable in your `.env` file
``` markdown [.env]
VITE_COOKIEBOT_ID=supersecret
```

### Use the environment variable in your Vue app configuration
``` ts [main.ts]
// Vendor
import { cookieBot } from '@ambitiondev/vue-cookiebot';
import { createApp } from 'vue';

// Components
import App from './App.vue';

const app = createApp(App);

app.use(cookieBot, {
	cookiebotId: import.meta.env.VITE_COOKIEBOT_ID,
});

app.mount('#app');
```
